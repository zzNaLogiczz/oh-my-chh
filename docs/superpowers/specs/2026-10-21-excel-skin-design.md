- 状态：草案，待用户审阅

- 来源：同级目录 `chhtest` 概念原型（2026-08-04）+ 2026-10-21 需求讨论

## 1. 意图

上班时刷 chh 帖子，怕同事和领导看到。用户在论坛调研过，这是 chh 网友的普遍需求——所以这是 oh-my-chh 面向全体用户的正式功能，不是自用玩具。

做法：开启后，chh 整站以「Excel 窗口」的样子呈现；有人走近时按老板键，画面瞬间切到用户自己导入的真实工作文件。

它是 remakeweb 架构（解析原页 → 结构化数据 → 插件自有界面渲染）的第二个皮肤，与 HeroUI 皮肤共用数据层，只是外壳不同。

## 2. 目标 / 非目标 / 反目标

### 目标（v1）
1. 打开 chh 任意受支持页面，第一帧就是 Excel 外壳，原站零帧外露。【用户定】
2. 覆盖四类页面：版块列表、帖子列表、帖子详情、搜索。【用户定】
3. 老板键一键切到用户导入的 `.xlsx`，再按一键回来。【用户定】
4. 随 oh-my-chh 下一个版本一起上架商店。【用户定】

### 非目标（v1 不做）
- 发帖、收藏等写操作【用户定】（回帖已于 2026-10-22 按用户要求加入，仅文字，见 4.15）
- 还原导入文件里的图表【用户定】
- 遮挡浏览器地址栏的 `chiphell.com`（已知露馅点，接受）【用户定】
- 公式重新计算；把改动写回导入文件【Claude 定】
- 消息、通知、个人空间、设置、发帖页等其他页面【用户定，范围外】

### 反目标（即使功能可用，出现即算失败）
- 任何时刻闪出原站：首次加载、站内跳转、解析失败、登录过期时都不行。
- 界面出现 chh 的样式、配色、logo，或任何“不像 Excel”的 UI（转圈加载、圆角卡片、HeroUI 组件、品牌渐变）。
- 老板键有可感知的延迟或闪烁。
- 用户导入的工作文件离开本机，或存进 `chiphell.com` 页面脚本能读到的位置（页面 `localStorage` / `IndexedDB`）。
- 浏览器标签页的标题或图标露出 chiphell。

## 3. 用户已定的产品决策

### 3.1 外壳
Excel 窗口结构：标题栏（`<导入文件名> - Excel`）、功能区（文件/开始/插入/页面布局/公式/数据/审阅/视图）、名称框 + 编辑栏、列头/行号、网格、工作表标签栏、状态栏。chhtest 的外壳是起点。

### 3.2 帖子详情 = 表格 + 右侧「批注」窗格【用户定，讨论中选项 C】
- 左侧表格一楼一行：楼层 / 作者 / 摘要。有正文的格子右上角显示 Excel 批注标记（紫色小三角）。
- 选中某一行，右侧批注窗格定位并高亮该楼：头像、作者、时间、正文段落。
- 【Claude 定】批注窗格可连续滚动通读整帖；左表起目录/跳楼作用。功能区「审阅」选项卡在此视图下处于激活态。

参考示意：`.superpowers/brainstorm/62841-1792569681/content/thread-reading.html`（选项 C）。

### 3.3 图片【用户定】
- 批注内默认以缩略图显示（讨论中选项 C）。
- **全局开关**：「默认有图 / 默认无图」两态，带快捷键。
- **单条开关**：每条批注可单独选择显示或隐藏图片。
- 【Claude 定】全局开关初始值为「默认有图」（与用户选的“直接显示缩略图”一致）。全局开关放在「视图」选项卡，呈现为 Excel 原生风格的勾选项；无图态下图片位收起为 `IMG_xxxx.jpg` 文件名标签，不留空白。单条开关放在批注右上角 `···` 菜单。切换全局开关时，所有单条手动设置重置为跟随全局。选择记在本机，跨帖子、跨重启保留。

参考示意：`.superpowers/brainstorm/62841-1792569681/content/images.html`（选项 C）。

### 3.4 老板键 → 用户导入的真实 Excel【用户定】
- 用户自己选一个 `.xlsx` 导入，插件记住。
- 按老板键：一键切到这份文件；再按：回到切走前的位置（同一页、同一选中格、同一滚动位置）。
- 不提供内置假报表模板（讨论中三张假报表均被否决：任何假数据都不如用户身边人见过的真文件可信）。

### 3.5 导入文件的还原度【用户定】
- 必须保留：单元格格式（数字格式、字体、字号、粗体/斜体）、颜色（填充色、字色）、合并单元格。
- 不需要：图表。
- 【Claude 定】同样保留：列宽、行高、边框、多个工作表（标签按原文件顺序与名称）、冻结窗格（若解析库可得）。公式不重算，格子显示文件保存时的缓存值；选中公式格时编辑栏显示原公式。图表所在位置留空，不画占位框。

### 3.6 打开即 Excel，不能闪原站【用户定】
见反目标第 1 条。适用于每一次页面加载。

### 3.7 地址栏不处理【用户定】
地址栏显示 `chiphell.com` 是已知且接受的露馅点。

## 4. Claude 定的方案选择（用户未否决，请审阅时核对）

### 4.1 落点：oh-my-chh remakeweb 的第二个皮肤
- 代码进 oh-my-chh（`remakeweb` 分支），与 HeroUI 皮肤共用解析数据层（目前在 `src/remake/home/data.ts`，需要抽出共享层）。
- chhtest 中已有并带测试的解析器（`src/discuz-html.js`：`parseForumIndexDocument` / `parseForumDisplayDocument` / `parseViewThreadDocument`，及 `test/discuz-html.test.js`）移植为 TypeScript 并入共享数据层；与 `scripts/remake/in-page/extractors.js` 的选择器对齐，以 remakeweb 的选择器文档 `scripts/remake/README.md` 为单一事实来源。
- 显示模式成为用户设置项（例：原版 / CSS 换肤 / Excel 伪装），在 popup 里切换。Excel 模式开启时，门户首页的 HeroUI 重绘（`content/remake-home.js`）与 CSS 主题资产不得同时生效，三者互斥。【实施者定】具体设置字段名与迁移方式。

### 4.2 Excel 界面手写，`UI-LIBRARIES.md` 登记例外
`UI-LIBRARIES.md` 规定“禁止手写仿制组件”。仿 Excel 本身就是产品，HeroUI 做不出 Excel 的视觉，因此 Excel 皮肤整体豁免该条，需在 `UI-LIBRARIES.md` 中登记例外及理由。HeroUI 皮肤仍受原规则约束。

### 4.3 导入时一次性解析，老板键只渲染
- 在扩展自有页面（options 页）完成导入：选文件 → 解析为规范化工作簿模型（值、缓存公式、样式、合并、尺寸、多表）→ 存入 `chrome.storage.local`。
- 老板键只读取已存模型并渲染，不现场解析，保证瞬时切换。
- xlsx 解析库只在导入页加载，不进入 content script 包。
- 存储位置硬性要求：只能存扩展隔离存储，禁止存 chiphell.com 页面源下的任何存储。
- 【实施者定】`chrome.storage.local` 默认配额约 10MB；超出时是申请 `unlimitedStorage` 权限还是限制可导入文件大小。注意：新增权限会影响商店审核，并需更新 `PRIVACY.md`。

### 4.3b 整个 Excel 界面在扩展源 iframe 内渲染
反目标要求工作文件不进入 chh 页面能读到的位置——这同样适用于**渲染**：chh 页面加载了第三方统计/广告脚本，若把工作簿内容画进页面 DOM（含 open shadow root），这些脚本理论上可读取。因此整个 Excel 界面（论坛视图 + 老板键视图）是一个扩展页面 `excel/app.html`（`web_accessible_resources`），以全屏 iframe 盖在 chh 页面上：
- 该页面直接读 `chrome.storage.local` 中的工作簿，数据永不经过页面上下文；老板键是 iframe 内部的视图切换，天然瞬时。
- content script 只做“宿主”：遮住原页、守卫标题/图标、同源抓取与解析 chh 页面、维护浏览器历史，把**解析后的论坛数据**经 `MessageChannel` 端口发给 iframe。
- 2026-10-21 实测：chh 的 CSP 仅 `upgrade-insecure-requests`，不限制 iframe；`static.chiphell.com` 图片与头像跨站加载正常（无防盗链），iframe 内可直接显示。【Claude 定】

### 4.4 帖子正文只取纯文本 + 图片地址
不把帖子原 HTML 注入界面：正文按段落抽取纯文本，图片取地址（优先 `zoomfile` 原图、`file` 属性），全部经 `textContent` / DOM API 写入。这样 CONCERNS A 组（HTML sanitizer）在本皮肤基本绕开。
【实施者定】表情、引用（楼中楼）、代码块、B 站视频 iframe、附件、`[hide]` 回复可见块在批注里的呈现方式；原则是“看起来仍像 Excel 批注”。

### 4.5 站内导航不整页跳转
在 Excel 内打开版块、帖子、翻页时，插件同源 `fetch` 目标页 HTML 并解析后原地渲染，同时 `history.pushState` 同步到真实 chh URL。这样从根上避免跳转闪原站；刷新或新开标签进入时，document_start 阶段重新接管即可。后退/前进由插件处理 `popstate`。

### 4.6 首次进入停在导入表
新标签页首次进入 chh 时默认显示用户导入的工作文件，用户切到论坛工作表再读帖；站内导航与刷新保持在论坛工作表。【实施者定】用什么记住“本标签已进入过论坛视图”（建议 `sessionStorage` 仅存一个布尔标记，不存内容）。

### 4.7 未导入文件时
老板键切到一个内置的空白工作簿。导入引导要低调、不露馅（如状态栏一行小字或「文件」菜单内入口），不弹显眼的引导层。

### 4.8 工作表标签与标签页
- 论坛相关工作表标签使用中性名字（如 `Sheet2`、`Sheet3`），不出现“版块”“帖子”“搜索”等字样。导入文件自己的工作表保留原名。
- 标签页标题在 document_start 起持续守卫为 `<显示文件名> - Excel`（未导入时用中性默认名，如 `工作簿1 - Excel`），需抵御页面后续写 `<title>`。
- 「显示文件名」在导入时可编辑，默认填入真实文件名。理由：`document.title` 对 chh 页面里的统计/广告脚本可见，可能被上报；文件名本身可能敏感。导入界面需一句提示说明这一点。【Claude 定】
- 标签页图标替换为通用绿色表格图标，**不使用微软官方 Excel logo**；商店文案描述为“表格风格界面/办公伪装模式”，不暗示与微软有关联——规避商店仿冒审核风险。

### 4.9 四类页面的布局
- **版块列表**：按分区分组，分区名为跨列合并的加粗标题行；每个版块一行：版块名 / 今日 / 主题 / 帖子 / 最后发表。双击或回车进入。
- **帖子列表**：每帖一行：标题 / 作者 / 回复 / 查看 / 最后回复；置顶帖以 Excel 风格区分（例如浅色填充）。双击或回车打开帖子；滚动到底自动加载下一页，行号连续。
- **帖子详情**：见 3.2、3.3。
- **搜索**：见 4.10。

### 4.10 搜索：Discuz 原生搜索（已验证可用）
2026-10-21 登录态实测：`GET search.php?mod=forum&srchtxt=<词>&searchsubmit=yes` 直接返回结果（302 到 `searchid=` 结果页），连续两次搜索未触发间隔限制；结果为 `li.pbw`（标题、回复/查看数、摘要、时间、作者、版块），分页 `.pg`。搜索入口做成 Excel「查找」框样式（`Ctrl+F` 唤起），结果按帖子列表样式呈现。若遇到 Discuz 搜索间隔提示（`#messagetext`），以 Excel 风格提示原文。

### 4.11 异常与逃生
- 沿用 remakeweb 四态（loading / empty / partial / error）。加载态是“格子已画、内容逐步填入”，不出现转圈；错误用 Excel 风格的状态栏提示或对话框。
- 「查看原页」逃生舱放在「文件」菜单内（如“在浏览器中打开原网页”），不放常驻浮动按钮。
- 登录过期（CONCERNS #10）：解析检测到未登录时，以 Excel 风格对话框提示需要重新登录，并通过「文件」菜单入口去原页登录。

### 4.11b 入口页与不支持的页面
- 用户“打开 chh”最常落在门户首页（`/`、`portal.php`），它不在 v1 四类页面内。Excel 模式下门户首页直接呈现版块列表（壳内同源抓取 `forum.php`）。
- 其他不支持的路由（消息、个人空间、设置、发帖等）被直接打开时，同样不显示原站：呈现 Excel 外壳 + 空工作表，状态栏提示“该内容在此模式下不可用”，「文件」菜单提供“在浏览器中打开原网页”（临时对本页退出 Excel 模式）。
- 论坛内容里指向不支持页面的链接，以普通文本显示或经「文件」菜单逃生，不触发整页跳转。【Claude 定】

### 4.12 网格交互
单元格可点选、方向键移动、滚动，可输入但不保存（像在干活）；论坛内容格只读。沿用 chhtest 的选择/编辑/编辑栏同步行为。

### 4.13 第一轮实测反馈后的追加（2026-10-22）
用户实测后提出 4 项，按下列方式落地：
- **频道导航 + 二级导航【用户定要有】**：版块列表顶部加「频道导航」分组，来自页头 `#nv` 与 `mn_*_menu`；A 列为频道，B–F 列为二级分类，每格各自可点（Excel 超链接样式），每行最多 5 个，多出折行。为让导航可用，门户频道列表（`portal.php?mod=list&catid=`）与门户文章（`article-aid-页.html` / `portal.php?mod=view&aid=`）纳入支持：列表按帖子列表样式（分类格可点进入子分类），文章按帖子详情样式（正文一行 + 最新评论，内容在批注窗格；评论只在第 1 页收录）。【实现方式 Claude 定】
- **返回【用户定要有】**：功能区最左侧加「导航」组（仅论坛工作表显示，导入的工作表上隐藏，老板键画面不变）。「后退」走浏览器历史，但只在应用内 pushState 过的条目上可用（深度记在 `history.state.omchhExcelDepth`），不会一步退出 chh；「返回上级」：帖子 → 所在版块的进入时那一页（伪静态链接第三段；帖内翻页时沿用进入时记下的上级），版块/搜索 → 版块列表，子分类/文章 → 所属分类，顶级频道 → 版块列表。【Claude 定】
- **翻页【用户定要有】**：同组内「上一页 / 第 [n] / 共 N 页 / 下一页」，可输入页码回车跳转；滚动到底自动追加仍保留，页码框显示已加载区间。任意页地址模板优先从页码链接推导（保留站点 URL 风格），退路是 Discuz 跳页输入框里的 `window.location='…'+this.value`。【Claude 定】
- **左右被遮挡【缺陷】**：根因两处——① 选中格子时用 `scrollIntoView`，不知道行号列与冻结行是 sticky 的，格子被推到行号列底下（选回 A 列后 A 列前 40px 被盖住），窄网格时整列移出视口；② 列宽固定 + `width:max-content`，长文本把多余宽度摊给所有列，窄窗口下右侧列在视口外。改为：只滚动网格自身并扣除 sticky 区；表格宽度钉为列宽之和；每张表指定一个主文本列，窗口不够宽时只收窄它（最窄 160px，不加宽）；功能区组不收缩，放不下的组整组隐藏。

### 4.14 皮肤收敛为「原版 / Excel 伪装」（2026-10-22）
- 【用户定】彻底删除液态（Spectrum）CSS 皮肤、Flat Clean、⌘K 命令面板与站内灯箱、门户首页 HeroUI 重绘；连同主题引擎、DOM 语义适配层、相关脚本 / 测试 / 依赖（React、HeroUI、Radix、Tailwind 等）。
- 【用户定】弹窗只有两张皮肤卡片：原版（扩展不改动页面）、Excel 伪装；选中哪个，下面只出现该皮肤的设置；去掉减弱玻璃、动效等设置项和说明文字；调试日志收进默认折叠的「高级」。
- 【Claude 定】设置字段改为 `skin: "original" | "excel"`（sync）；旧 `displayMode: "excel"` 读取时迁移为 Excel 皮肤，保存时清掉全部旧字段。Excel 偏好（窗口标题、老板键、图片开关键、默认显示图片）直接在弹窗里改；快捷键须带 Ctrl/Alt/⌘ 或为 F1–F12，且两键不能相同。导入页只管工作簿（拖入 / 选择 / 移除），因为弹窗打开文件选择框会失焦关闭。
- 弹窗外框圆角由 Chrome 绘制，扩展无法控制（Chrome 扩展团队 2024-12 确认）；页面内容不贴边画边框。

### 4.15 帖子详情里回帖（2026-10-22）
- 【用户定】读帖时在右侧批注窗格回帖，暂时只支持文字：可以选某一楼答复，也可以在窗格最下方的输入框回复楼主。文章评论不在范围内。
- 【Claude 定】仿 Excel 线程批注：选中的卡片底部出现「答复…」框（··· 菜单里也有「答复」），点开就在这张卡片里写；窗格底部常驻「回复楼主…」，没聚焦、没内容时收成一行。Ctrl / ⌘ + Enter 发布，Esc 关闭楼层答复框；草稿留在内存里，同一帖子内翻页或关闭答复框再打开都还在。
- 【Claude 定】只有页面带快速回复框（已登录、帖子未关闭、有回帖权限）才出现回帖入口；凭据（fid、formhash）从快速回复框里取。
- 提交都由宿主（content script）同源发出，沿用当前登录会话：回复楼主 = 快速回复框的同款表单（`handlekey=fastpost`）；答复某楼 = 先取这一楼的回复表单（楼主那一楼用 `reppost`，其他楼 `repquote`），连同服务器生成的引用内容与加密的「通知层主」字段一起提交，层主才能收到提醒。chh 开了 Discuz 的 ajax 校验，ajax GET 必须带 `X-Requested-With: XMLHttpRequest`（2026-10-22 实测：不带时返回整页）。
- 回执按 Discuz ajax 格式解析：`succeedhandle_*` 为成功（取新回帖 pid），`errorhandle_*` 为失败，把服务器原话显示在输入框下方，正文保留。没有回调脚本但提示含「成功」时也按成功处理，避免用户以为失败又发一遍。
- 【Claude 定】发布成功后不打断阅读：已加载到最后一页时，经 `findpost` 重取新楼层所在页，只追加没显示过的楼层并选中新楼层；否则停在原处，底部提示「已发布 · 查看」，点「查看」才跳过去。需要审核时显示服务器的提示。

### 4.16 设置页改为中性通用样式（2026-10-22）
- 【用户定】插件的目的是自由切换皮肤，设置页不能沿用 Excel 的风格；logo 用插件自己的图标；皮肤用下拉框选择（原版 / Excel 伪装），取代 4.14 的皮肤卡片。
- 【Claude 定】弹窗与导入页共用一套中性配色（灰白 + 系统字体），唯一的强调色取自插件图标的深石板蓝 `#1e293b`；所选皮肤的设置放在以皮肤名命名的分组里。皮肤列表是一处常量，下拉选项和设置分组都由它生成，加皮肤只加一条。
- 【用户定】manifest 版本号保持 0.2.0；描述改为「Chiphell（chh）论坛专用美化插件，可自由选择多款样式。」，不提具体皮肤。

## 5. 约束

- **oh-my-chh 不变量**（`docs/refactor-plan.md` §1.2）：只注入 `https://www.chiphell.com/*`；权限仅 `storage`（新增须论证并更新 `PRIVACY.md`）；无远程代码；不采集 cookie/表单/隐私数据；关闭插件后页面回到原站可用状态。
- **零外部请求**：Excel 皮肤不得加载 Google Fonts 等外部资源（现 HeroUI 首页 `standalone.tsx` 加载了 Google Fonts，Excel 皮肤不得沿用）；字体只用系统字体（Windows `Segoe UI` / `Microsoft YaHei`，macOS 回退 `PingFang SC`）。图片只来自 chh 自身的图片地址。
- **首屏不闪**：利用现有 `src/platform/preflight.css`（document_start 前隐藏 body 的机制）；Excel 模式下原 body 永不显示，外壳在 document_start 阶段尽早挂载。
- **性能预算**：沿用 `docs/refactor-plan.md` §2.2——首屏包（`content/main.js`）≤100KB minified；按需包 ≤350KB minified；xlsx 解析库不得进入 content script。
- **隐私文档**：`PRIVACY.md` 需新增：导入的 xlsx 仅存本机扩展存储、不上传、不同步、可在设置中删除。
- **快捷键**：【实施者定】默认值与冲突处理；建议老板键沿用 chhtest 的 `Alt+1`（语义相同：快速回到工作簿），图片全局开关另配；均可在设置中修改，输入框聚焦或输入法组合中不触发（chhtest `matchesQuickReturn` 已有此逻辑）。
